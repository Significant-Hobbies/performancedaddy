# Hardware implementation references

The original, read-only SMC and IORegistry adapter was informed by these MIT-licensed implementations. It contains no fan-control/write operations, privileged helper or external runtime dependency.

- Stats: https://github.com/exelban/stats/tree/88d5359ad3466efaa16985646a0bb15c6599109f/SMC
- Mac Performance Monitor: https://github.com/Zesty0wl/mac-performance-monitor/tree/bfbd512dd5e2e00b763f8b58e2986e3549885fd7/Sources/MacPerfMonitorCore/Sampling
- macmon: https://github.com/vladkens/macmon/blob/afdd572b12c9c301183569230a476bd4267b638b/src/sources.rs

These driver interfaces are undocumented and version-dependent. Missing readings remain unavailable. PerformanceDaddy does not use IOReport energy mappings whose units/refresh behavior have not been validated.
